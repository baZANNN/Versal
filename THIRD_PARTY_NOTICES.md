# Third party notices

Versal uses third party packages under their respective licenses. The npm lockfile
records exact versions and license metadata; installed packages contain their
own license and notice files. Preserve applicable notices when redistributing
dependencies or a bundled application.

The initial application structure came from the Vinext starter distributed with
the OpenAI Sites tooling. The public copy uses Vinext and the Cloudflare Vite
plugin directly; it does not contain personal Sites deployment configuration.

The project consulted
[Brent Vollebregt's spotify-lyrics-viewer](https://github.com/brentvollebregt/spotify-lyrics-viewer)
for comparisons of behavior and architecture. Consult that repository for the
license of its source.

Spotify provides playback metadata and LRCLIB provides lyric records at runtime.
No song lyric catalog is distributed in this repository. The MIT license on
Versal's code does not change the rights or terms that apply to those services
or their content.
